# Practice scope — fictional Northstar Learning Hub

All pages, content and differences in this exercise are fictional. The collector
captures real HTTP responses from local sample files; it does not audit a live client.

Inventory: /, /resources/, /contact/, /guide/. Map source /guide/ to target /help/.
The required checklist download is /downloads/checklist.txt, referenced by the
home and resources pages. It must return the approved sample checklist.

Required browser exercises: follow both download links, compare resources
headings/guidance, compare contact layout at 1440x900 and 390x844, operate help
disclosures with mouse and keyboard, and navigate between every scoped page.
The layout must fit each viewport without horizontal scrolling. Use the same
viewport and interaction state on each side. Do not send messages: the contact
address is fictional and there is no backend.

The missing checklist blocks this exercise's required download journey (P0 if
confirmed by the reviewer); the omitted resources heading/guidance and mobile
contact overflow are P1 in this fictional scope. Priorities do not transfer to
real projects without their own acceptance criteria.

Do not label checks pass/fail until performed. Static Good does not mean the
visual/functional review passed. Broad accessibility conformance, production
SEO/indexing, authentication, external services and release approval are outside
this local teaching exercise. Record unperformed required checks as Unverified.
