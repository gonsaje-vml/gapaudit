# Downloadable practice audit

The user approved a downloadable practice kit with sample sites, a walkthrough,
and GitHub Pages publication, then requested much deeper file and skill explanations
with diagrams and charts for visual learners.

Build on the existing Python-only guide and explicit publish allowlist. Use four
fictional local pages and the real collector, with no credentials, API key or Node
installation for the initial exercise. Include a mapped route, one missing
download used on two pages, omitted resources guidance/H1, and a CSS-only contact
layout defect to teach the boundary between collection and browser review.

The runner serves source and target on loopback, collects into a new output
directory and keeps the sites open for browser review; a one-shot mode supports
automated verification. Ports are configurable. Existing runs must never be
overwritten. A serve-only command reopens fixtures without recollecting.

Publish a dedicated visual walkthrough, a separate complete practice ZIP, and a
home-page practice section. Package the walkthrough and its SVG diagrams for
offline reading. Cover each delivered input, output and skill file, record
dependencies and judgment boundaries, explain readiness chart units, provide
expected results, troubleshooting, agent prompts and the transition to real sites.

The full PDF is an optional reviewed extension with pinned dependencies. Do not
invent browser observations or imply that static measurements establish readiness.
Reuse the existing audit skill rather than introducing a second competing skill.
Do not publish historical client runs or unrelated workspace files.

Alternatives: saved-evidence replay is simpler but skips collection; public demo
URLs add hosting dependencies. The approved local-site practice kit teaches the
whole flow reproducibly while retaining a Python-only starting point.
